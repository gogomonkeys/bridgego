## 遊戲流程

玩家用語統一為「場 → 局 → 回合」：一場共 3 局，一局共有 13 回合；四人各出一張牌才算完成一個回合。贏得這四張牌算拿下一墩；「回合」表示出牌進度，「墩」表示個人或隊伍拿下的數量。個人操作稱「輪到你出牌／叫牌」，每次操作各自倒數，不把個人出牌當成一整個回合。此處僅調整稱呼，規則、計分與 API 欄位不變。

四位不同訪客入房 → 四人準備 → 房主開始 → 發牌 → 選特權 → 喊牌 → 出完 13 回合 → 每局計分。前兩局結算後進入獨立確認畫面；四人確認或 90 秒到期後才發下一局。第三局結束顯示總結。

每局結算畫面只顯示本局與累計分數、四位玩家的確認狀態及 90 秒倒數，不顯示下一局手牌。每人按一次「下一局」；四人都確認可提前繼續，否則到時自動前進。只有前進時才發新牌並啟動新的特權倒數。斷線會暫停局間倒數，沿用 10 秒重連／判負規則。

## 已確認的玩法

### 座位、特權與喊牌

- 四人在線且全部準備後，由房主按開始，不自動開局。
- 對家為一隊：北／南與東／西。四人各自控制自己的牌，不設夢家、加倍或再加倍。
- 每局看完牌後、喊牌前選特權，每局都可使用。同隊任一人使用即成立，兩人都不用才確定不用；雙方結果一起公開。
- 特權階段共用 20 秒期限，未選者逾時視為不用，不取消隊友已成立的使用選擇。提交選擇不會延長其他人的時間。
- 喊牌 1～7 階；同階順序梅花＜方塊＜紅心＜黑桃＜無王，須高於上一叫價。每次叫牌 20 秒，逾時自動 Pass。
- 有叫價後連續三次 Pass 定約；四人開頭全 Pass 則重發、重選特權，不算完成一局。

### 出牌

- 採「左喊右攻」：叫牌依左手邊輪流；最後叫到牌者的右手邊首引，出牌依右手邊輪流；每回合贏家先出下一回合。
- 有首出花色必須跟；沒有時才能出任意其他花色或王牌。
- 一回合中有王牌時，最大王牌勝；否則首出花色最大牌勝。A 最大，無王沒有王牌。
- 每次出牌 20 秒，逾時後端自動出一張合法小牌，紀錄標示自動操作。
- 一局完整 13 回合，只能由後端依實際出牌與拿下墩數結算，前端不能自行提交成績。

每回合第四張牌打出後，會保留四張牌約 2 秒，標示贏家與贏牌，再讓贏家先出下一回合。這段時間不扣下一人的 20 秒出牌時間。第 13 回合也先顯示四張牌，再進結算。一般回合結果展示期間斷線會暫停展示並保留原本重連規則；第三局最後一張牌已完成全場計分，之後斷線／離開不會改判。

### 自訂計分

喊 n 階時，進攻方目標為拿下 6+n 墩：

- 達標基本分 +n。
- 恰好達標再加 Bonus +(n+1)，超額墩不另加這項 Bonus。
- 未達標扣 n 分。
- 防守方一般分數為 0。
- 使用特權的隊伍，該局贏再 +2，輸再 −1。

例如喊 2、剛好拿 8 墩：2+3=5 分，若使用特權則得 7 分。進攻方未達標就是防守方贏。三局累計總分高者獲勝，同分平手。

## 中途退出與斷線

- **等候室：**偵測到最後一條連線中斷即釋位、取消準備，沒有 10 秒保留期。回來需重新加入，有空位才可入座。
- **遊戲中網路斷線：**偵測後保留原身分、座位、手牌 10 秒，暫停操作倒數。期限內恢復，所有人在線後接續剩餘操作時間，不重新發牌。
- **主動退出遊戲：**立即棄權，退出者所屬隊伍判負，另一隊勝；即使退出隊目前分數較高也一樣。
- **重連逾時：**逾時者所屬隊伍棄權判負；若兩隊都未能在各自期限內恢復，記為中止、無勝負。
- 已完成局的分數保留，未完成局不加減分。結果會區分正常分數勝負、棄權與無勝負，並記錄觸發者。

兩隊先後離線時，每人仍保有原本的 10 秒。在第一隊逾時後，只等待對方當時已在進行的重連期限：對方及時回來則第一隊棄權；對方也逾時則無勝負。不會因較晚的新斷線無限延長判定。

終局結果不會因後來有人離線或離房而改判。同一訪客在終局離線後可回來查看結果；這是結算讀取權，不是等候室座位保留。主動離房會釋放房間席位；上一場結算的權限與保留範圍見下節。後端重啟會清空記憶體資料。

同一訪客多分頁只占一席，另一分頁仍有有效連線時不算整位玩家斷線。首次 HTTP 加入至 WebSocket 訂閱有獨立 5 秒交接清理期限，不是遊戲重連寬限。無聲斷網需要先被連線探測發現，探測時間與 10 秒重連期分開計算。

## 終局房間與再玩一場

- 未重開的房間標示「已結束」，不誤稱遊戲進行中；新玩家不能直接加入舊牌局。
- 在線房主按「再玩一場」後，房間回到等候室，保留在線者的座位、釋放離線者席位，所有人取消準備。四人重新在線並準備，再由房主開始，才建立新的牌局與手牌。
- 終局房主離開或離線時，由座位編號最小的在線成員接任；若全員離線，首位回來者可接任。這不改變已結束的勝負。
- 上一場結算獨立保存，只供原參賽身分查看；新玩家即使坐到同一座位也看不到上一場資料。封存不包含未出的手牌或未公開的特權選擇。
- 本機只保留該房間最後一場的結算；更新的終局取代舊封存。所有人按離房後刪除房間及其記憶體封存，服務重啟也會清空。這不是永久戰績功能。

## 本版明示的實作預設

- 首局從北位開始喊牌；每完成一局，首叫座位順時針輪替。全 Pass 重發不換首叫座位。
- 座位依北→東→南→西輪轉。候場房主離開，剩餘座位編號最小者接任。
- 特權提交不可撤回；隊友已選使用時不必再提交。
- 自動出牌先選合法牌中點數最低者，同點數依梅花、方塊、紅心、黑桃順序決定。這不是智慧代打策略。
- 終局由在線房主按「再玩一場」回到同一房間的等候室；不直接開始新牌局。

## Windows 本機開發啟動（5173 不註冊 PWA）

需要完整 JDK 17 或更新版本、Maven 3.9+、Node.js 22.12 以上的 22.x 或 24.x，以及 npm。測試工具的 Node 需求不能只以 Vite 最低版本替代。

先在舊前後端 PowerShell 按 Ctrl+C。**建議解壓到新資料夾，保留舊版作備份**，不要混用不同版本的前後端。

第一個 PowerShell，在專案根目錄：

```powershell
cd backend
mvn clean package
java -jar target/bridge-room-successor-0.7.1.jar
```

第二個 PowerShell，在專案根目錄：

```powershell
cd frontend

npm run dev
```

開啟 http://127.0.0.1:5173 ，按 Ctrl+F5，確認 V0.7.1。這是開發模式，刻意不註冊 Service Worker；測 PWA 請用上方正式建置的 localhost:8080。後端為 http://127.0.0.1:8080。服務只綁定本機，其他電腦或手機不能直接加入，不是已上線的公開多人網站。

測四人請使用四個獨立瀏覽器使用者設定檔；同設定檔的新分頁會共用訪客，多個無痕視窗也可能共用身分。後端重啟會清空訪客、房間及牌局，需要重新建立測試訪客。個人修改請先自行備份。

## 建議驗收

1. 四人準備、房主開始，確認私人手牌與隊伍。
2. 選特權、完成喊牌，確認最後叫到者右手邊先出，並依右手邊輪流出牌。
3. 測跟花色限制、王牌與無王、逾時自動合法出牌。每回合第 4 張牌須留在桌面約 2 秒，能看出贏牌／贏家；下一人的 20 秒在展示後才開始。核對各座位拿下墩數與兩隊已結算累計。
4. 完成一局，確認結算畫面沒有下一局手牌。測四人確認提前前進，以及不確認等 90 秒自動前進；確認後才發牌、開始特權倒數。
5. 完成三局，核對累計與勝負；由房主「再玩一場」，確認準備全部清除、在線玩家留座、空位可加入、新牌局不沿用舊狀態。
6. 另開場測短暫斷線重連、逾時棄權及主動退出。雙方斷線案例請注意各自期限。
7. 若連線異常，複製「連線診斷」並附後端同時段紀錄；不要提供 token、密碼或未出手牌封包。
