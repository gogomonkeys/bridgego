# Isolated C maintenance runner

Core `SyntheticCRelease.BUNDLED` is deliberately unprovisioned. Ordinary backend packaging excludes `quartercore/SyntheticC*` and `synthetic-c/**`. Only a separate, reviewed C-online staging copy may bind the fixed newly approved target, dataset, source revision, baseline full-token and equivalent-before artifact SHA. No target, baseline, owner or permission is accepted from HTTP/arguments/environment. The only environment inputs are the existing lazy service-account JSON source and HTTP port. No live command has been executed by these files.

Reuse: the bounded Google read-only factory, new journal quarter sink, HTTP budgets and lazy credential handling follow the earlier maintenance launcher. The old `test.arm.A` workflow is NOT reused: an out-of-band metadata insertion would invalidate the journal digest. No digest exclusion or ordinary-authority widening was added.

Before credentials, the runner verifies bundled `/synthetic-c/before-native.json` bytes against its SHA, strictly decodes the full native fixture and checks the exact release full-token/journal. This is an equivalent restorable fixture, not falsely labeled a captured Google response. The first live read must match it exactly. The setup operator separately saves the actual Google full read and manifest outside the runner. Baseline mismatch rejects, including restart after any applied mutation.

The runner serves maintenance-only health and no gameplay. Private Render logs contain `C_PRIVATE_APPROVAL`: fixed target, dataset, revision, operation, quarter, baseline, before-artifact SHA, five-phase scope, fixed ordinary-check policy, expiry, digest and a random 256-bit nonce. The authorized operator, within the already approved restorable C scope, submits exactly one `POST /execute`, `Content-Type: application/json`, `Authorization: Bearer <private nonce>` and body `{ "previewDigest": "<exact digest>" }`. Nonce must never be put in URL/chat/repository or sent to another service. No browser login or per-phase confirmation is introduced. Origin-bearing and chunked requests are rejected; only the digest is accepted in the body. Wrong tokens do not invalidate the real pending nonce. HTTP size/deadline/connection budgets and disabled server logging match the prior launcher.

Approval consumes the nonce before any write. A five-minute grant authorizes only the five journal quarter phases. On success the quarter handle is retired before the fixed synthetic ordinary hook (new owner, identity/profile, formal match, casual match, clean close). Unknown execution is terminal and triggers one separate read-only review; an apparently completed marker does not permit replay or claim success. Shutdown closes both current transport and ordinary hook, outside the launcher lock, then interrupts workers. Public health replies never include approval material or data.

This validates C's journal cleanup and ordinary sink checks, not an online crossing-quarter active-game drain, actual player migration, unrestricted restart, or formal automatic cleanup deployment. No normal game health setting is modified by this candidate.
