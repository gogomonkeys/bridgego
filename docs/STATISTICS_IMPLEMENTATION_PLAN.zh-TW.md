基準：`gogomonkeys/bridgego` 的 `pwa-beta-v0.7.0`，提交 `562cea6185103069cd40722f4be26c9f3f8f1a7d`。此文件記錄候選程式，不代表已推送、部署、啟用保存或完成真實 Google／Sheets 驗收。

## 已確定的產品規則

- 訪客看不到統計入口，也不能讀取個人或整體統計 API。登入玩家可由大廳進入個人／整體頁面。
- 四個獨立真人控制的座位正常完成一場後可計，包含訪客與登入玩家混合的場次，也包含四訪客場次。
- 以伺服器完成結算的當下判斷。中途有電腦代打但真人已回來可計；結算時仍有電腦／電腦接手不計。
- 訪客沒有個人統計，也不在新統計紀錄中保存訪客名稱、訪客識別碼或登入憑證。
- 個人戰績依結束時間與台灣季度處理，既有 1、4、7、10 月季度人工清理方向維持；本次沒有執行刪除。
- 排行榜與其他低優先項目未加入。

## 執行順序與目前程式範圍

1. **結算資格與最小資料：已實作。**
   - 第一個 terminal 結算轉移固定資格，不等最後兩秒展示結束。
   - 檢查完整四席、不同玩家身分、已知登入帳號不重複、真人在線且沒有電腦控制。
   - 伺服器無法證明不同訪客身分背後一定是不同自然人，不把這項檢查稱為真人身分驗證。
2. **保存與個人／整體計算：已實作，預設不啟用。**
   - 僅 managed 模式且既有保存設定可用，再明確設定 `BRIDGE_STATISTICS_ENABLED=true` 才開放。
   - 新入口在玩家選擇遊玩前顯示資料使用說明。玩家繼續時以目前版本確認，伺服器只在房間外接收，且新開局時固定全場真人的確認狀態。
   - 舊客戶端、未看到新說明的既有房間、缺任一真人確認的場次不進入新統計，不暗中視為同意。
   - 合資格新紀錄在既有 match JSON 增加 `statistics_rule: four-humans-at-settlement-v1`。不新增 Sheets 欄位或資料表。舊紀錄缺乏可信結算資訊，不回補。
   - 個人只以伺服器驗證連結的帳號計算；全場訪客不建立個人識別。訪客位置仍有隊伍與遊戲結果，但 `account_id`、`guest_id` 均為 null。
   - 個人與整體目前都顯示台灣時間本季、同一計分規則、已確認保存的正常完成場次。
   - 個人顯示場次、局數、勝／負／平手及我方累計分數；整體顯示場次、局數和平手。不加入未定義分母的勝率或個人叫牌表現。
3. **大廳與畫面：已實作，待最終實機驗證。**
   - 登入狀態與功能可用性確認後才顯示入口。訪客直接輸入統計 hash 仍無頁籤／資料。
   - 載入、空資料、不可用、重試、返回大廳與瀏覽器導覽；登入變更及工作階段變更清除舊資料。
   - 進行中房間優先顯示牌桌，統計導覽不能取代進行中的牌局。
4. **發布與線上驗收：尚未執行。**
   - 最終套件核對、程式檢查、適當發布授權後，先核對線上提交，再驗證真實四人對局與保存／畫面。
   - 本機測試、合成資料瀏覽器驗證及真實 Google／Sheets 驗收分開報告。

## 安全與隱私界線

`SettlementEligibility` 的結果碼不帶身分。只有新規則標記且符合格式的結果進入統計；重複快照只計一次，衝突、未來日期或錯誤數值拒絕處理，不挑其中一份猜算。

`GET /api/statistics` 不接受查詢目標帳號。訪客一律 403，登入者只得到自己的彙總及不含識別的整體數字，不返回場次 ID、帳號／訪客 ID、姓名、座位明細或精確對局時間。讀取與外部 Sheets I/O 不持有遊戲鎖；讀完再檢查帳號有沒有切換。無快取，避免保留已刪除個人結果。並行讀取設限，未取得資料時顯示不可用而不是假的 0。

新原始紀錄仍是營運者私人資料，不因去掉訪客識別就宣稱整份原始對局已匿名。已登入參與者保留既有同意的帳號歸屬；不記 Google 名稱、信箱、頭像、憑證或完整手牌。

原有手動季度清理與帳號刪除已增加新欄位相容性，維持原本確認與離線限制。帳號刪除移除該帳號的歸屬，保留同場其他人的資料和不帶該身分的整體結果。先前季度的 `quarterly_aggregates` 仍只維持 `SUPPRESSED`，沒有自動開放歷史數字或自動刪除。

## API 與啟用

- `GET /api/statistics/config`：公開功能狀態與 `statistics-v1` 告知版本。
- `PUT /api/statistics/consent`：有效訪客工作階段、本站 Origin、房間外、明確布林與正確版本。確認只存在工作階段內，非新長期訪客身分。
- `GET /api/statistics`：有效工作階段且已登入帳號，AVAILABLE／DISABLED／UNAVAILABLE；不可用時兩種彙總均為 null。

開關預設 false。現有 managed 保存服務、私人資料集、季度 COMPLETE 與 erasure ledger 守門仍須符合原條件。缺配置不能只改這個旗標強行啟用。功能關閉時沿用既有保存規則；受限測試與單人實驗不套用新統計保存。

本版未調整永久帳號保存、未執行刪除、未建立新憑證或權限、未設定自動化。
