# BridgeGo｜橋牌 GO！

在森林裡和朋友湊一桌。BridgeGo 是採自訂規則與計分的四人橋牌遊戲，手機與電腦都能用瀏覽器玩。

**[開始玩 BridgeGo](https://bridgego.onrender.com)** · **[看宣傳短片〈林間那一桌〉](media/BridgeGo-Forest-Teaser-v6.mp4)** · [近期版本紀錄](CHANGELOG.md)

## 怎麼開始

1. 用 Google 登入，或以訪客身分進入，不必先註冊。第一次請設定遊戲暱稱，最多 10 字；Google 帳號已有暱稱會沿用。
2. 到大廳開啟「新手教學」，或直接建立／加入房間。可選 1、3 或 5 局。
3. 把房間代碼傳給朋友；登入玩家也能從等待室邀請好友。就緒後由房主開始。
4. **正式場**須四位真人；**休閒場**可加入電腦，自己也能練習。

## 大廳與等待室

- **排行榜**可看本季與生涯。訪客可以看榜；符合正式場統計資格的登入玩家自動入榜，先比積分，再比勝率。
- **個人統計**供登入玩家查看本季及生涯戰績。
- **我的好友**可查看好友狀態及發出房間邀請。房間等待期間可用文字聊天或選擇開啟語音。
- **語音預設關閉。** 若選擇語音直連，可能向同房參與者分享 IP 位址。

## 上桌小提醒

對面是隊友。一局 13 墩，有首引花色就要跟花；叫牌與出牌各有 30 秒。倒牌、特權與計分請以遊戲內的「使用說明」為準。

遊戲需要網路，加入手機主畫面也不能離線打牌。若服務正在喚醒，請稍等；服務重啟可能中斷進行中的牌局，不等於清除已保存的帳號或戰績。
