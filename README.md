# 橋牌 GO！BridgeGo

和朋友一起玩的四人橋牌小遊戲，採自訂規則與計分。手機、電腦都可以直接用瀏覽器加入。

## 🎮 直接試玩

### [點這裡開始玩 →](https://bridgego.onrender.com)

**不用下載原始碼，也不用註冊帳號。** 第一次開啟如果比較慢，請稍等服務喚醒，再重新整理。

## 第一次玩，照這樣做

1. 輸入 1–5 字的訪客名稱，按「以訪客身分進入」。
2. 選擇 **1、3 或 5 局**，按「建立四人房間」。第一次試玩可選 1 局。
3. 把遊戲網址與房間代碼傳給朋友；朋友進入後輸入代碼即可加入。
4. 人數不足時，房主可在等候室加入 **1–3 位電腦玩家**，一個人也能試玩。
5. 真人按「我準備好了」，電腦會自動準備。四個座位都就緒後，由房主按「開始遊戲」。

每位玩家請使用自己的裝置或獨立瀏覽器設定檔。同一瀏覽器的多個分頁會共用訪客身分，不能當成不同玩家。

## 玩法小提醒

- 對面的玩家是隊友，兩隊各兩人；每人控制自己的牌。
- 一局 13 回合。有首引花色就必須跟花；沒有時才可出其他花色。
- 採「左喊右攻」：叫牌往左輪流，最後叫到牌者的右手邊先出，出牌往右輪流。
- 叫牌、出牌有操作倒數；手機先選牌，再按「出這張牌」。
- 這是自訂橋牌玩法，沒有夢家、加倍或再加倍。倒牌、特權與計分請看遊戲內「使用說明」或[完整玩法](README.zh-TW.md#已確認的玩法)。

## 試玩版注意事項

- 目前是 **Beta 測試版**，最多兩個房間、每房四席。房間滿了請稍後再試。
- 使用公開訪客大廳，知道網址的人都能進入；房間代碼不是私人存取權限。請勿輸入密碼或私人資料。
- 免費主機可能休眠，開啟時需要等待；服務更新、休眠或重啟可能中斷遊戲。訪客、房間與牌局只存記憶體，重啟後無法復原。
- 遊戲需要網路。可依瀏覽器支援加入主畫面，但不支援離線打牌。
- 手機切到背景、鎖屏或網路不穩可能影響連線；不保證所有裝置都有相同體驗。

## 回報問題

請到 [GitHub Issues](https://github.com/gogomonkeys/bridgego/issues) 回報，附上：
- 發生時間、手機／電腦、瀏覽器名稱。
- 你做了什麼、預期結果、實際畫面或錯誤訊息。
- 畫面上的版本號；截圖請遮住私人資料，勿貼訪客 token、密碼或未出手牌。
