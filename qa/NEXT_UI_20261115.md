此次候選以已公開的舊版為基底，62 個核心改動檔案由已核對的 Git 物件精確恢復。前端套件版本檔重新生成後，其兩個 blob 雜湊亦與遠端既存物件相同。兩份 README 與本摘要重新撰寫，因此是重新驗證的候選，不宣稱與先前候選完整 tree 相同。未包含原始私人 QA、玩家資料或憑證。

以下皆為恢復後重新執行，不以先前執行紀錄替代：
