# 統計條件與正確性審查

2026-11-10，v0.13.0 發布前審查，未藉測試操作正式資料；線上狀態另行核驗。範圍涵蓋固定房型、終局、逐局耗時、本季／生涯、保存、季度清理及刪帳；最終測試數量另見 `MATCH_CATEGORIES_AND_TIMING_VALIDATION.md`。

## 計算定義

| 項目 | 判定與累計 |
| --- | --- |
| 正式／休閒 | 開房固定，重開同房不變；四真人休閒仍休閒。正式禁止電腦與重複已知帳號。 |
| 總場次 | 每筆已確認保存的終局計一次，含 SCORED、FORFEIT、NO_CONTEST；另顯示三種分項。 |
| 勝／負／平手 | 正常結束按總分；退出／逾時判負按失敗隊伍；中止不算勝、負、平手。 |
| 勝率 | wins / (wins + losses + draws)；包含判負，排除中止；分母 0 顯示 —，不能用總場次當分母。 |
| 積分 | 每場已完成局之我方結算分數總和，再累加場次；可為負，中止仍保留完成局分，判負不改造成額外扣分。 |
| 完成局 | 只計第 13 墩最後一張牌已提交並完成計分的局；多局中斷保留已完成局，未完成局無分數／耗時列。 |
| 耗時 | 每局第一次發牌至計分提交，含倒牌、斷線等待，排除最後展示與局間等待；不以整場時間平均。 |
| 本季 | finished_at 按 Asia/Taipei 季度，下一季 1／4／7／10 月 1 日 00:00 為 exclusive 邊界；開始時間跨季不改結果所屬季。 |
| 生涯 | 只有 account-career-v1 新標記、同一計分版本的已存資料；已封存帳號彙總加本季新標記資料，不加入匿名整體或其他帳號。 |

## 安全與一致性檢查

1. **權威來源與不可重寫。** 只有伺服器終局可建立保存資料，最後一張牌鎖定正常結果，後續離開不能改判。原開局帳號與資格檢查固定，不受正式退出後裁定窗內切換帳號影響。
2. **正式判負與中止。** 主動離開、10 秒未恢復各有理由；同隊一負，近乎同時雙方失敗中止。1 秒固定裁定窗，只等待既有對手重連期限；新斷線不無限延長。多分頁與過期 socket 關閉不誤判。
3. **完整／部分局分離。** v3 校驗完成局數與連續序號，SCORED 必須打滿；FORFEIT／NO_CONTEST 必須少於預定局數；總分必須等於逐局分數和。零局終止可計場次，不捏造分數。
4. **房型、終局、理由一致。** 正式禁止 BOT/MIXED；CASUAL/FORFEIT 拒絕。NO_CONTEST 的理由與房型對應。勝方可與當時分數領先方不同，只在正式判負時成立。
5. **可證明的保存。** 僅 verified committed export 計算；重複完全相同資料去重，衝突同場／版本不任選。不可用時返回 null／UNAVAILABLE，不沿用舊快取或假 0。
6. **帳號隔離與訪客。** 帳號來自伺服器連結，不接受查詢別人帳號；訪客不可讀個人或整體 API。新資料無訪客識別，事後登入不認領訪客紀錄。API 不返回帳號、場次ID、對手或原始牌局。
7. **同意範圍。** statistics-v4 明示跨季私人累計。開局全場真人確認狀態固定；未確認新版不保存新統計。lifetime_rule 只能出現在固定房型新資料；無標記舊資料不能變成生涯保存同意。
8. **跨季原子性。** 過期原始對局刪除與帳號 E 欄累加在既有同一個七表原子批次；成功讀回後才寫 COMPLETE。核心與 live adapter 均獨立重算預期帳號欄位，不能藉清理改暱稱、清空或灌入生涯數字。
9. **防重放與失敗恢復。** carry.through 是已累計區間的 exclusive 終點；重疊舊資料拒絕。未套用／回應不明／PENDING／已完成都分開處理，同計畫不盲重寫。新計畫完成已套用的 PENDING 不再累加已移除原始資料。
10. **讀取同代資料。** 核對前後 retention、erasure 與目標帳號 row，並檢查讀取完成時間的季度；跨界或中途刪帳／carry 改變整體不可用，不混合舊 carry 與新季度空資料。
11. **刪除與登入更新。** 刪帳移除整個 account row 含 E，原始紀錄歸屬移除，ledger 阻止復活；其他人 carry 不變。登入只更新 A:D，實際 Google request builder 不寫／清 E，讀回也檢查原樣保留。
12. **嚴格格式與數值。** carry JSON 僅允許指定欄位、版本與季度邊界，拒絕重複鍵、尾隨內容、非整數、溢位、不一致分項及無完成局卻有分數。計數限定安全整數，不默默截斷或四捨五入累計值。
13. **歷史相容。** v1/v2/v3 原有本季語意保留；缺耗時顯示未知。已清除或未同意生涯保留的歷史不臆測，生涯標示為功能啟用後可證明資料及最早季度，可能少於含舊記錄的本季數字。

## 驗證對應

- 房型／正式退出：`FixedRoomModeTest`、`FixedRoomTypeHttpTest`。
- 統計終局／部分局：`FixedRoomStatisticsTest`、`FixedRoomEnvelopeTest`。
- 本季／生涯 API 與帳號切換：`LifetimeStatisticsServiceTest`、`LifetimeStatsExportTest`、既有 `StatisticsServiceTest`／`StatisticsHttpTest`。
- 生涯 JSON、去重、跨季 fold：`LifetimeStatisticsTest`。
- 同批清理、回應不明、PENDING 重試、刪帳：`LifetimeRetentionTest` 與既有維護／刪除 suites。
- 私人 E 欄與工作簿：`LifetimeAccountProfileTest`、`LiveQuarterLifetimeTest`、live storage suites。
- 前端勝率、積分、截止時間、scope 切換與無資料：`statistics.test.tsx` 等；CUA 合成頁面操作另由前端驗證記錄說明。

## 仍需明確區分的限制

- 季度切換是統計時間界線，不是自動清理排程。既有停全部寫入者、人工確認、清理 COMPLETE 守門維持；未完成會暫停新季保存／統計讀取，不能承諾無人操作仍持續可用。
- E 欄升級需既有工作簿有 A:E 容量；不足會拒絕，不擅自修改工作簿結構。發布須一起更新 app 與四種隔離操作工具，舊讀取器可能拒絕新格式。
- 停全部寫入者是既有操作前提，不是分散式鎖。Google Sheets 版本史、營運備份不會因目前資料集刪帳／清理自動消失，不能宣稱所有外部副本都已刪除。
- 以上是本機與合成資料驗證；未進行真實多人、Google、Sheets 寫入或正式清理。未加入部署、資料遷移、歷史回填或自動監控。
